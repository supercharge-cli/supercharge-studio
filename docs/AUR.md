# Arch Linux (AUR): supercharge-studio-bin

`supercharge-studio-bin` repackages the release `.deb`. Each GitHub Release includes a
ready-made `PKGBUILD` and `SRCINFO.txt`, generated by the release workflow from the
`packaging/aur/PKGBUILD.in` template with the real sha256. The workflow also test-builds the
package with `makepkg` in an `archlinux:base-devel` container. CI does the same on every
push (`AUR package` job, which also runs `namcap`).

## Install from a release, without the AUR

```sh
mkdir supercharge-studio-bin && cd supercharge-studio-bin
curl -fLO https://github.com/iotserver24/supercharge-studio/releases/latest/download/PKGBUILD
makepkg -si
```

## Publish or update the AUR package (maintainer)

```sh
git clone ssh://aur@aur.archlinux.org/supercharge-studio-bin.git
cd supercharge-studio-bin
curl -fLo PKGBUILD   https://github.com/iotserver24/supercharge-studio/releases/download/vX.Y.Z/PKGBUILD
curl -fLo .SRCINFO   https://github.com/iotserver24/supercharge-studio/releases/download/vX.Y.Z/SRCINFO.txt
makepkg -f && git add PKGBUILD .SRCINFO && git commit -m "Update to X.Y.Z" && git push
```

Generate locally from any `.deb`: `scripts/aur.sh <version> <path/to.deb> [download url]`.
The output goes to `packaging/aur/out/`.

The Supercharge CLI is an optional dependency. The app finds it in `~/.local/bin` and the
other usual places, and offers to install it if it is missing.
