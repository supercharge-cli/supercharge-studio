# What's new in Supercharge Studio
<!-- Notes for the next release, one bullet per user-visible change. The release workflow publishes this file as the GitHub Release notes and the app shows them in the update prompt. Replace the bullets after each release. -->

- New look: a darker terminal-style design with thin borders, You and Agent labels on messages, boxed starter commands and chips in the message box.
- New themes, including Graphite, Carbon, Midnight, Forest, Ember, Arctic and Twilight. The phone lists them all and follows your system theme until you pick one.
- Settings → Appearance: density, border style, prompt symbol, cursor shape, accent color and optional scanlines, with a live preview. Plus a shortcuts sheet and a connection test.
- Settings → Providers now matches the Supercharge CLI: add any provider it supports, including routers, local servers and custom endpoints, then pick a model.
- Paste a key, or sign in in your browser or with a code. Keys stay with the CLI and are never shown again. Change model, replace a key or remove a provider anytime.
- Older Supercharge CLI? Providers keeps the previous setup and asks you to update. After a first-time CLI install, Studio opens Providers for you.
- Skipped a version? You also get the Public URL override (1.0.39), the Windows browser fixes (1.0.41) and anonymous usage stats with an opt-out (1.0.42).
