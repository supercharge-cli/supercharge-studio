# What's new in Supercharge Studio
<!-- Notes for the next release, one bullet per user-visible change. The release workflow publishes this file as the GitHub Release notes and the app shows them in the update prompt. Replace the bullets after each release. -->

- Windows: the built-in browser now stays exactly inside the Browser pane. Before, it could sit too far left, come out smaller than the pane and cover the chat, mostly on a 125% or 150% display and sometimes after changing the display scale or moving the window to another monitor.
- The browser and the AI cursor now follow resizing, maximizing, dragging the divider and scale changes right away, so the cursor stays lined up with the page while the agent works.
- Skipped 1.0.39? Updating also brings its earlier changes: the Public URL override, the phone composer fix, full model details, the Lean accent, compact Settings and update notes.
