# What's new in Supercharge Studio
<!-- Notes for the next release, one bullet per user-visible change. The release workflow publishes this file as the GitHub Release notes and the app shows them in the update prompt. Replace the bullets after each release. -->

- Public connection: the official Public URL (wss://relay.superchargeai.in) is now fixed and shown read-only. You can override it with your own ws:// or wss:// URL; leave it empty to use the official one. Fresh installs start with the custom field empty.
- Phone composer: the context-window picker is no longer cut off, and the "Auto" hint only shows when Auto is selected.
- Model pickers on the computer and phone show each model's full id (never shortened), its name and its description.
- Lean mode: when the Supercharge CLI runs its Lean agent, the app switches to a teal accent with a thin top bar so you can see it's a different agent.
- Settings on the computer: more compact layout, with the app version shown under the menu.
- Update prompts now show what's new in the update.
